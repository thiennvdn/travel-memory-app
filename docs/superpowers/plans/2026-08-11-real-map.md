# Real Map for MapScreen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the fake x/y-grid map in `MapScreen` with a real geographic map (react-native-maps) showing memories at real lat/lng, centered on the user's GPS location when permission is granted.

**Architecture:** Add `react-native-maps` + `expo-location` as dependencies. Migrate `Memory` mock data from relative `x`/`y` to real `latitude`/`longitude`. Add a small pure helper (`getRegionForCoordinates`) that computes a map region fitting a set of coordinates — used both as the map's default/fallback region and, later, reused conceptually for centering logic. Rewrite `MapScreen` to render a real `MapView` with custom-styled `Marker`s, then layer in a GPS permission request that recenters the map on success and silently keeps the bounding-box fallback on denial/error.

**Tech Stack:** Expo SDK 51, React Native 0.74.5, `react-native-maps` 1.14.0, `expo-location` ~17.0.1, TypeScript.

- [ ] **Step 1: Create the bounding-region helper**

Create `src/utils/mapRegion.ts`:

```typescript
export type Coordinate = { latitude: number; longitude: number };

export type Region = {
  latitude: number;
  longitude: number;
  latitudeDelta: number;
  longitudeDelta: number;
};

const PADDING_FACTOR = 1.4;
const MIN_DELTA = 0.05;

// Tính vùng bản đồ (region) vừa đủ để chứa hết danh sách toạ độ, có đệm (padding).
export function getRegionForCoordinates(coordinates: Coordinate[]): Region {
  const latitudes = coordinates.map((c) => c.latitude);
  const longitudes = coordinates.map((c) => c.longitude);

  const minLat = Math.min(...latitudes);
  const maxLat = Math.max(...latitudes);
  const minLng = Math.min(...longitudes);
  const maxLng = Math.max(...longitudes);

  return {
    latitude: (minLat + maxLat) / 2,
    longitude: (minLng + maxLng) / 2,
    latitudeDelta: Math.max((maxLat - minLat) * PADDING_FACTOR, MIN_DELTA),
    longitudeDelta: Math.max((maxLng - minLng) * PADDING_FACTOR, MIN_DELTA),
  };
}
```

import { getRegionForCoordinates } from "../utils/mapRegion";

Then, inside `export default function MapScreen() {`, right after the existing `const [selected, setSelected] = useState<Memory | null>(null);` line, add:

```tsx
  const [showsUserLocation, setShowsUserLocation] = useState(false);

  useEffect(() => {
    let cancelled = false;

    async function centerOnUser() {
      try {
        const { status } = await Location.requestForegroundPermissionsAsync();
        if (status !== "granted") {
          return; // giữ nguyên initialRegion (đã canh vừa khung chứa hết pin)
        }
        const position = await Location.getCurrentPositionAsync({});
        if (cancelled) return;
        setShowsUserLocation(true);
        mapRef.current?.animateToRegion(
          {
            latitude: position.coords.latitude,
            longitude: position.coords.longitude,
            latitudeDelta: 0.05,
            longitudeDelta: 0.05,
          },
          400
        );
      } catch {
        // Lấy vị trí lỗi -> giữ nguyên initialRegion (fallback âm thầm).
      }
    }

    centerOnUser();
    return () => {
      cancelled = true;
    };
  }, []);
```

Finally, add the `showsUserLocation` prop to the `<MapView>` element:

```tsx
        <MapView
          ref={mapRef}
          style={styles.map}
          initialRegion={initialRegion}
          showsUserLocation={showsUserLocation}
        >
```
